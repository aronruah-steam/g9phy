核心概念：從自然哲學思辨到運動學定量描述

亞里斯多德 vs 伽利略 · 運動學名詞

亞里斯多德的運動理論自然 vs 強制

亞里斯多德依物體本性將運動分為兩類，認為「力是維持物體持續運動的原因」：

  • 自然運動：由四元素（土、水、氣、火）本性決定。土與水「重性」大故向下落，愈重落得愈快；火與氣較輕故向上升；天體本性永恆，作等速圓周運動。
  • 強制運動：違反本性的運動（如斜拋砲彈）。必須持續施以「外力」才能維持運動；一旦外力消失，物體便恢復自然運動或靜止。

伽利略的實驗與慣性推論科學實證革命

伽利略透過自由落體思考與雙斜面實驗，推翻維持兩千年的亞氏學說：

  • 落體等快：空氣阻力才是輕物落得慢的主因；在無阻力下，無論輕重皆具有相同的重力加速度，且下落速度與時間成正比（$v \propto t$），而非與距離成正比。
  • 斜面思想實驗：鋼球沿光滑斜面向下滾再滾上另一斜面時，總會試圖回到原高度；當右斜面放平為水平面且無摩擦時，球將永遠維持等速直線運動（即「慣性」概念的萌芽）。
物理量 性質與單位 定義與數學式 關鍵觀念與比較
質點與坐標 模型 / m 以帶有全部質量的「點」簡化真實物體；在參考原點上建立數線描述位置 $x$。 當物體大小或形狀對研究問題影響極小時，即可簡化為質點；直線運動以 $+$、$-$ 表示方向。
位移 $\Delta x$ 向量 / m $\Delta x = x - x_0$（末位置 $-$ 初位置） 只與起、終點有關，與路徑無關；直線單向無折返時 $|\Delta x| = \ell$，若有折返則 $|\Delta x| < \ell$。
路徑長 $\ell$ 純量 / m 運動軌跡的實際總長度（又稱路程） 恆為非負值，必須知道完整軌跡才能求出。任何運動過程皆滿足 $\ell \ge |\Delta x|$。
速度 $v$ 向量 / m/s 平均速度 $\bar{v} = \frac{\Delta x}{\Delta t}$；瞬時速度 $v = \lim_{\Delta t \to 0}\frac{\Delta x}{\Delta t}$ 方向與位移同向；$x\text{–}t$ 圖的切線斜率代表瞬時速度，割線斜率代表平均速度。
速率 純量 / m/s 平均速率 $= \frac{\ell}{\Delta t}$；瞬時速率 $= \lim_{\Delta t \to 0}\frac{\ell}{\Delta t}$ 一般而言平均速度量值 $\le$ 平均速率；但當 $\Delta t \to 0$ 時，瞬時速度量值 $=$ 瞬時速率（如汽車時速表）。
加速度 $a$ 向量 / $\text{m/s}^2$ 平均加速度 $\bar{a} = \frac{\Delta v}{\Delta t} = \frac{v - v_0}{\Delta t}$ $v\text{–}t$ 圖的斜率為加速度，線下面積為位移；$a$ 與 $v$ 同向則加速，反向則減速。
函數圖形判讀口訣： 在直線運動中，$x\text{–}t$ 圖斜率＝速度（水平線表靜止、斜直線表等速、拋物線表等加速）；$v\text{–}t$ 圖斜率＝加速度，$v\text{–}t$ 圖與時間軸所夾面積＝位移（時間軸上方為正位移、下方為負位移）；$a\text{–}t$ 圖面積＝速度變化量 $\Delta v$。

公式推導教學與典型範例

等加速運動三大核心公式

等加速運動公式推導（圖形面積法）Derivation

設物體作等加速直線運動，初速為 $v_0$、加速度為定值 $a$，歷時 $t$ 後末速為 $v$：

1. 速度與時間關係：由定義 $a = \frac{v - v_0}{t}$ 移項可得
$$v = v_0 + at$$
2. 位移與時間關係：$v\text{–}t$ 圖形為上底 $v_0$、下底 $v$、高 $t$ 的梯形面積
$$\Delta x = \frac{(v_0 + v)}{2}t = v_0 t + \frac{1}{2}at^2$$
3. 不含時間的關係式：將 $t = \frac{v - v_0}{a}$ 代入 $\Delta x = \frac{v_0 + v}{2}t$
$$v^2 = v_0^2 + 2a\Delta x$$

典型範例 1：折返運動的位移、速率與加速度講義經典例題

小瑋將溜溜球以 $1.0\text{ m/s}$ 的速率鉛直向下擲出，經 $2.0\text{ s}$ 後球以相同速率、相反方向（向上）回到原出發點手中。已知最低點離手 $0.5\text{ m}$，求全程之：(1) 平均速度量值；(2) 平均速率；(3) 平均加速度量值。

解題步驟（定向下為正）：
(1) 球回到原點，總位移 $\Delta x = 0\text{ m}$，故平均速度 $\bar{v} = \frac{0}{2.0} = 0\text{ m/s}$。
(2) 向下 $0.5\text{ m}$ 再向上 $0.5\text{ m}$，總路徑長 $\ell = 0.5 + 0.5 = 1.0\text{ m}$，故平均速率 $= \frac{1.0}{2.0} = 0.5\text{ m/s}$。
(3) 初速 $v_0 = +1.0\text{ m/s}$，末速 $v = -1.0\text{ m/s}$，速度變化 $\Delta v = (-1.0) - (+1.0) = -2.0\text{ m/s}$。平均加速度 $\bar{a} = \frac{-2.0}{2.0} = -1.0\text{ m/s}^2$，量值為 $1.0\text{ m/s}^2$（方向向上）。

典型範例 2：$v\text{–}t$ 圖面積與未知時間計算課本習題

一物體自靜止作直線運動，全程歷時 $60\text{ s}$：前 $t$ 秒等加速至 $30\text{ m/s}$，接著以 $30\text{ m/s}$ 等速行駛至第 $60\text{ s}$。若全程平均速度為 $20\text{ m/s}$，試求 $t$ 值。

解：總位移 $\Delta x = \bar{v} \cdot \Delta t_{\text{總}} = 20 \times 60 = 1200\text{ m}$。
利用 $v\text{–}t$ 圖面積（三角形＋矩形）$=$ 總位移：
$\frac{1}{2}(30 \cdot t) + 30(60 - t) = 1200 \implies 15t + 1800 - 30t = 1200 \implies 15t = 600 \implies t = 40\text{ s}$。

核心概念：牛頓三大運動定律與生活中常見的力

慣性 · $F=ma$ · 作用與反作用力

第一運動定律（慣性定律）Law I

若物體不受外力或所受合力為零，則靜者恆靜，動者恆作等速直線運動。

  • 慣性決定因素：物體的慣性大小只由「質量」決定（質量愈大，慣性愈大），與物體速度無關。
  • 生活實例：公車急煞人向前傾、揮動鋼筆甩出墨水、等速車廂內鉛直上拋球落回原手、旋轉雨傘水滴沿切線飛出。

第二運動定律（運動定律）Law II

物體受不為零的合力作用時，產生的加速度與合力成正比、與質量成反比，且加速度方向必與合力同向。

  • 數學式：$F_{\text{合}} = ma$。
  • SI 單位定義：使 $1\text{ kg}$ 物體獲得 $1\text{ m/s}^2$ 加速度的力為 $1\text{ 牛頓 (N)}$。
  • 單位換算：$1\text{ kgw} = 9.8\text{ N}$（常簡化為 $10\text{ N}$）。

第三運動定律（作用反作用）Law III

甲施力於乙時，乙必同時施給甲一個量值相等、方向相反、共線的反作用力，寫作 $\vec{F}_{\text{甲}\to\text{乙}} = -\vec{F}_{\text{乙}\to\text{甲}}$。

  • 關鍵辨析：兩力作用在不同物體上，因此絕對不能互相抵消！
  • 辨認技巧：「施力者」與「受力者」互換（例：地球吸人 $\leftrightarrow$ 人吸地球），與「兩力平衡」（同作用於一物）截然不同。
常見作用力 公式與方向 重要物理性質與考點提醒
重力（重量 $W$） $W = mg$（方向指向地心） 質量 $m$ 不隨地點改變；重量 $W$ 隨重力加速度 $g$ 改變。地球表面 $g \approx 9.8\text{ m/s}^2$。
彈力（虎克定律） $F = k \Delta \ell$（回復方向） 在彈性（比例）限度內，彈力與形變量 $\Delta \ell$ 成正比。兩端各拉 $400\text{ gw}$ 的彈簧，其張力為 $400\text{ gw}$（非 $800$）。
正向力（$N$） 垂直於接觸面並指向受力物 屬接觸力，用來防止物體穿透接觸面；量值不一定等於物重（如斜面上或有上下外力時）。
摩擦力（$f_s, f_k$） 平行接觸面，阻礙「相對運動趨勢或滑動」 靜摩擦力 $f_s$：相對靜止時存在，大小等於平行面外力（$0 \le f_s \le f_{s,\max}$）。
動摩擦力 $f_k$：相對滑動時存在，$f_k = \mu_k N$，與接觸面積及滑動快慢無關，通常 $f_k < f_{s,\max}$。

公式推導教學與典型範例

受力圖分析 · 系統法與隔離法

牛頓定律與運動學連結推導Derivation

1. 平均施力與動量變化：將 $a = \frac{\Delta v}{\Delta t}$ 代入 $F = ma$
$$F_{\text{平均}} = m \frac{v - v_0}{\Delta t}$$
2. 連結體加速度（系統法）：兩物塊 $m_1, m_2$ 並聯受水平定力 $F$
$$a = \frac{F}{m_1 + m_2} \quad ; \quad \text{內力 } T = m_2 a = \frac{m_2}{m_1 + m_2}F$$
3. 有摩擦時的加速度：當外力 $F > f_{s,\max}$ 開始滑動後
$$a = \frac{F - f_k}{m}$$

典型範例 1：球棒擊球平均打擊力課本與講義範例

投手將質量 $0.15\text{ kg}$ 的棒球以 $144\text{ km/h}$ 水平投進本壘，打擊者以 $60\text{ m/s}$ 反向擊出。若球與球棒接觸時間為 $0.02\text{ s}$，求球受到的平均打擊力量值。

解：先統一單位：$144\text{ km/h} = \frac{144}{3.6} = 40\text{ m/s}$。
定擊出方向為正，則初速 $v_0 = -40\text{ m/s}$，末速 $v = +60\text{ m/s}$。
速度變化 $\Delta v = 60 - (-40) = 100\text{ m/s}$。
由 $F = m\frac{\Delta v}{\Delta t} = 0.15 \times \frac{100}{0.02} = 750\text{ N}$。

典型範例 2：靜摩擦力與動摩擦力判斷常見迷思

一質量 $1\text{ kg}$ 物體靜置水平面（$g=10\text{ m/s}^2$），最大靜摩擦力 $f_{s,\max} = 2\text{ N}$，動摩擦力 $f_k = 1.5\text{ N}$。若施以水平力 $F = 3\text{ N}$，求物體加速度與所受摩擦力。

解：因施力 $3\text{ N} > f_{s,\max}(2\text{ N})$，物體已開始滑動，此時受動摩擦力 $f_k = 1.5\text{ N}$。
合力 $F_{\text{合}} = 3 - 1.5 = 1.5\text{ N}$，加速度 $a = \frac{1.5}{1} = 1.5\text{ m/s}^2$。

核心概念：從地心說到克卜勒行星運動三大定律

天文觀測 · 歸納法 vs 演繹法

第一定律：軌道定律1609

太陽系的每一顆行星都沿著橢圓軌道繞太陽運行，且太陽位於該橢圓的其中一個焦點上（非正中心 $O$）。

平均軌道半徑 $R$ 定義（半長軸 $a$）：
$$R = \frac{r_{\min} + r_{\max}}{2} = a$$

第二定律：面積定律1609

同一顆行星與太陽的連線，在相等的時間內掃過相同的面積（面積速率 $\frac{\Delta A}{\Delta t} = \text{定值}$）。

  • 速率變化：行星並非等速率繞日！在近日點距離最近，速率最快；在遠日點距離最遠，速率最慢。
  • 適用範圍：僅適用於「同一顆行星」的不同位置；不同行星各自的面積速率不同。

第三定律：週期定律1619

繞行同一中心天體的所有行星，其平均軌道半徑 $R$ 的三次方與公轉週期 $T$ 的平方之比值為一定值。

$$\frac{R_1^3}{T_1^2} = \frac{R_2^3}{T_2^2} = K$$
對太陽系行星，若 $R$ 用 AU、$T$ 用年，則 $K = 1\text{ AU}^3/\text{年}^2$。
比較項目 歸納法（Inductive Reasoning） 演繹法（Deductive Reasoning）
推論方向 由具體、大量的觀測或實驗數據出發，不預設立場，歸納出背後隱藏的共同規律。 由已知的基本定律或公理出發，經過嚴謹的邏輯與數學推導，得出特定情境的結論。
代表人物與貢獻 克卜勒：分析老師第谷長達二十餘年的精確天文觀測數據，歸納出三大行星運動定律，使哥白尼「日心說」獲得強力佐證。 牛頓：從牛頓三大運動定律與萬有引力定律（平方反比重力）出發，透過數學推導證明出克卜勒三大行星運動定律。

軌道幾何推導與典型範例

克卜勒常數 $K$ 的適用條件

橢圓軌道半長軸與週期比值推導Geometry

設橢圓半長軸為 $a$，中心 $O$ 至焦點 $F_1$ 距離為 $c$，則：

  • 近日距 $r_{\min} = a - c$；遠日距 $r_{\max} = a + c$。
  • 平均軌道半徑 $R = \frac{r_{\min} + r_{\max}}{2} = \frac{(a - c) + (a + c)}{2} = a$（注意：不是 $\frac{a+b}{2}$！）。
  • 若以地球繞太陽為基準（$R_{\text{地}} = 1\text{ AU}$，$T_{\text{地}} = 1\text{ 年}$），任一繞太陽天體皆滿足 $R^3 = T^2$（單位為 AU 與年）。

典型範例：由近／遠日距求公轉週期講義範例

某繞太陽公轉之小行星，其橢圓軌道的近日距為 $3\text{ AU}$，遠日距為 $5\text{ AU}$。試求此小行星的：(1) 平均軌道半徑 $R$；(2) 公轉週期 $T$。

解：
(1) 平均軌道半徑 $R = \frac{r_{\min} + r_{\max}}{2} = \frac{3 + 5}{2} = 4\text{ AU}$。
(2) 利用克卜勒第三定律，與地球（$R_{\text{地}}=1\text{ AU}, T_{\text{地}}=1\text{ 年}$）比較：
$\frac{R^3}{T^2} = \frac{1^3}{1^2} \implies \frac{4^3}{T^2} = 1 \implies T^2 = 64 \implies T = 8\text{ 年}$。

全章重點精要與常見迷思辨析

考前速覽 · 觀念除錯
常見錯誤迷思 正確物理觀念 關鍵判據與舉例
「物體速度為 0 的瞬間，加速度必定為 0。」 錯誤！速度與加速度沒有必然同時為零的關係。 鉛直上拋到達最高點瞬間，$v = 0$，但物體仍受重力，加速度依然向下且 $a = g$。
「力是維持物體運動的必要原因。」 錯誤！力是用來「改變」物體運動狀態（產生加速度），不是維持運動。 由牛頓第一定律，在無摩擦水平面或外太空中，不受外力仍可維持等速直線運動。
「作用力與反作用力大小相等、方向相反，所以可以抵消。」 錯誤！兩力分別作用在不同物體上，無法合成或抵消。 馬拉車前進是因為「地給馬的向前靜摩擦力」大於「車拉馬的向後拉力」（看單一受力體的合力）。
「靜止物體受的是靜摩擦力，運動物體受的是動摩擦力。」 錯誤！關鍵在「與接觸面間是否有相對滑動」。 人在地面行走時（車輪純滾動無打滑），腳底或輪胎與地面接觸點「相對靜止」，提供推進的是靜摩擦力！（賽車無花紋光頭胎可在乾燥跑道增大接觸摩擦）
「月球繞地球的 $R^3/T^2$ 與水星繞太陽相同。」 錯誤！克卜勒第三定律僅適用於繞「同一中心引力天體」的衛星或行星。 月球繞地球、福爾摩沙七號繞地球兩者比值相等；火星與地球繞太陽兩者比值相等，但兩組不能直接畫等號。
